<p>Messages — простое SMS-приложение для Android на Kotlin и Jetpack Compose
(Material 3). Оно полностью работает офлайн: в манифесте нет
<strong>разрешения INTERNET</strong>, поэтому сообщения покидают устройство
только через вашего оператора.</p>

<b>Возможности</b>

* Чистый интерфейс Material 3 со светлой / тёмной / системной темой
* Список переписок с поиском, значками непрочитанных и аватарами
* Закрепление, архивация, корзина (+ отмена) и удаление; свайпы
* Черновики сохраняются автоматически для каждой переписки
* Отложенные сообщения и необязательная задержка отправки
* Пересылка сообщений и кликабельные ссылки
* Отправка и получение изображений MMS (как приложение SMS по умолчанию)
* Поддержка двух SIM с выбором SIM для каждого сообщения
* Статус отправлено / доставлено / ошибка для каждого сообщения с повтором
* Блокировка номеров и действия в стиле жалобы на спам
* Резервное копирование и восстановление базы данных
* Без рекламы, без аналитики, без трекеров

<b>Разрешения</b>

Разрешения на SMS и контакты используются только для отправки/получения
сообщений и показа имён контактов. Приложение вообще не запрашивает доступ к
сети.
